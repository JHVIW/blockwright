# Example critiques and build logs

These are the real working notes from the example cottagecore set: four of its buildings are shown in the README,
and three of their scripts ship in `examples/builds/`. They are kept verbatim as references for agents:
- `critiques/NN_roundK.md`: the format a critic should write, and the kinds of fixes that moved a build from
  about 4/10 to about 7/10;
- `logs/NN_slug.md`: a builder's plan and iteration log.

Paths such as `tmp/critic03r2/` and `builds/bNN_*.py` refer to that project's layout. In a blockwright workspace
the equivalents are `scratch/critic_<slug>_r<k>/` and `builds/<slug>.py`. The numbering ("building 02") refers to
that set.
